# CodeAlpha Internship Tasks

This repository contains three full-stack projects developed as part of my CodeAlpha internship.

## Projects

### 1. E-Commerce Website
A web application for browsing products, searching and filtering items, managing a shopping cart, and handling user accounts and orders.

Folder: `E-Commerce/`

### 2. Project Management Tool
A collaborative application for organizing projects, managing tasks, assigning work to team members, and sharing comments.

Folder: `Project-Management-Tool/`

### 3. Meet Up — Real-Time Communication App
A real-time communication application featuring meeting rooms, audio/video calling, screen sharing, chat, file sharing, and a collaborative whiteboard.

Folder: `Meet-Up/`

## Repository Structure

- `E-Commerce/` — E-commerce project source code.
- `Project-Management-Tool/` — Project management project source code.
- `Meet-Up/` — Real-time communication project source code.

## Setup

Refer to each project's individual README for its setup instructions and required dependencies.

**Security:** Do not commit passwords, API keys, environment files containing secrets, session tokens, or private user data.
